# OnTop Atendimento IA — Premium

Área protegida com IA Groq, limite diário no Upstash, login por código enviado pela Brevo e integração Kiwify.

Webhook: `POST /api/webhooks/kiwify?token=SEU_KIWIFY_WEBHOOK_TOKEN`

Eventos de compra aprovada liberam a conta e enviam o código. Reembolso, chargeback e cancelamento bloqueiam o acesso.
